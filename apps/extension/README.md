# 启程 · 投递填表助手

独立的 Chrome / Edge 浏览器扩展。本体只提供右上角的应用市场入口和安装包；模型生成使用插件自己的本机服务，不访问本体数据库，不参与聊天、面试或记忆开关。

## 安装

1. 从启程右上角「应用」下载安装包并解压到固定目录。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 打开「开发者模式」，选择「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的目录。
4. 在浏览器工具栏固定「启程 · 投递填表助手」。需要 Chrome/Edge 120 或更新版本。

这是本地安装版，尚未发布到浏览器应用商店。网页不能代替浏览器完成扩展安装。

## 使用：统一以 Excel 资料表为准

1. **从简历生成**：导入 PDF/DOCX/TXT/Markdown，点击「解析简历并导出 Excel」。也可在「从启程导入」登录后，点击「从启程简历一键生成 Excel」。两种入口都会生成相同的 `.xlsx` 表。
2. **补充并保存**：在 Excel/WPS 修改「字段值」，补充期望月薪、薪资月数、期望年薪、意向岗位/城市、到岗日期等。缺失值留空；插件不会推算补造。启用列设为「否」可排除该行。可新增自定义字段行。
3. **重新导入表格**：点击插件顶部「导入资料表」，选择已保存的 `.xlsx`。下次投递可直接导入此表，不必再解析简历。原文件不会被自动覆盖或监视，外部编辑后需重新导入。
4. **AI 匹配页面**：打开企业投递表单，点击底部固定按钮「用表格资料让 AI 匹配当前页」。只把已启用、非空的表格资料和页面字段描述/选项送给本地 `.env` 模型服务，不回退使用简历原文。
5. **核对后填入**：模型返回表格字段与页面字段的引用关系；描述超限时可逐字摘选该字段原文，不允许编造内容或执行代码。实际输入框值来自表格；下拉选项限定为页面现有选项。核对预览后点击「确认填入选中的字段」，网站的保存/投递由本人操作。

插件内「查看和编辑表格资料」也是当前表的数据；修改后可再次导出保存成新 Excel。没有简历时也可直接导出空白模板，填好后导入。

资料表包含「启用、字段名称、字段值、字段标识、备注」；字段标识用于追踪数据，新增行留空时自动生成。支持有计算结果的 Excel 公式；请先在 Excel/WPS 重算并保存，未计算公式或错误单元格会提示修正。旧版 `.xls` 请另存为 `.xlsx`。

薪资需注明单位。明确的元/月与 K 单位可做确定性换算；月薪、年薪及薪资月数不会互相替代。无法确认的日期、单位、控件和多段重复经历会保留待手动核对。

分步表单每进入下一步需重新识别。默认保留页面已有内容；需要替换时勾选「允许覆盖页面已有内容」。

本地 PDF/DOCX 解析不需要启程和模型服务。扫描件、加密 PDF 或无法提取文字的文件需要先转为文字版或粘贴文字。最大 20 MB、50 页、30,000 字。

## .env 模型配置（v0.2.0）

开发时配置 `apps/extension/.env`：

```dotenv
MODEL_API_BASE=https://api.deepseek.com
MODEL_NAME=你的模型名称
MODEL_API_KEY=你的真实Key
```

```powershell
# 项目根目录启动独立服务，Node.js 22 或更新版本
pnpm plugin:serve
```

配置修改后重启该服务，不需要重新打包或更改本体。前后端服务不依赖此进程；不使用自动生成时也不必启动它。

仅使用安装包时：将 `.env.example` 复制为同目录 `.env`，填写参数，然后运行 `node service.mjs`，Windows 也可双击 `start-model-service.cmd`。服务始终读取 `service.mjs` 同目录的 `.env`。

本地服务通过固定插件标识限制请求来源。首次升级到 v0.2.0 请重新下载安装包并加载；若旧扩展仍显示模型配置输入框，请移除旧扩展，再加载新版解压目录。此后保留固定标识即可稳定升级。不要将包含真实 Key 的目录重新压缩分享。

## 支持范围

常见中英文个人信息、教育、专业技能、工作与项目经历，以及用户在 Excel 补充的薪资、到岗时间、意向岗位和自定义字段。模型不会从姓名推断拼音、不会补造个人资料。

支持原生输入框、文本域、下拉选择，填充后触发 input/change 事件；遍历可访问的同源 iframe 和开放 Shadow DOM。日期信息不完整时不会补造具体月日。重复的同类字段、尚未适配的复杂下拉、多段教育记录、跨域 iframe、文件上传、单选及复选题需手动处理。工作、实习、项目、实践、在校任职、奖励与竞赛使用经历明细，逐条选择填写。

没有对某个招聘平台宣称全量兼容。通用识别依赖页面语义标签；无法确认的字段会跳过，请核对结果。后续网站适配只需修改扩展，不需要修改本体。

## 数据与权限

- 本地读取文件；点击「解析简历并导出 Excel」或从启程生成表格时，简历文字经本机服务发送至 `.env` 配置的模型服务。点击 AI 匹配时只发送当前表中启用且非空的资料和页面控件描述。
- 会话中的表格资料、简历文字和可选启程登录令牌只使用 `chrome.storage.session`，关闭浏览器或清除资料后失效。模型和连接地址保存在插件设置中。
- 模型 Key 只保留在本机 `.env`，不进入扩展包、浏览器存储、网页或日志；安装包只有空值 `.env.example`。
- 「清除资料」清除本次会话的简历文字和资料；「断开连接」仅清除启程令牌，不更改本体数据。
- 通过 `activeTab` 在用户操作时临时访问当前页。模型服务只监听 `127.0.0.1:18765`，只接受固定插件标识的请求。访问启程需单独授权对应域名；不持续监听所有网站。
- 密码、验证码、证件号、银行账户及未明确支持的字段不自动填充；API Key 与登录令牌不会传给招聘页面。

## 开发

```powershell
pnpm install
pnpm --filter @workplace-agent/application-assistant test
pnpm --filter @workplace-agent/application-assistant build
```

构建输出：`apps/extension/dist`（可直接加载），安装包输出：`apps/web/public/plugins/application-assistant.zip`。插件构建是独立命令，本体构建不依赖插件源码；本体只分发打包好的静态 ZIP。

真实浏览器检查：配置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 为 Chromium 可执行文件后，运行 `pnpm --filter @workplace-agent/application-assistant test:browser`。可选设置 `TEST_APP_URL=http://localhost:5173` 验证应用市场；该检查使用模拟登录和接口响应，不修改真实账号或简历。

测试页面：`tests/form-fixture.html`，只用于本地验证，不向任何企业投递。

实现依据：[Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[会话存储](https://developer.chrome.com/docs/extensions/reference/api/storage)、[PDF.js](https://mozilla.github.io/pdf.js/examples/)、[Mammoth](https://github.com/mwilliamson/mammoth.js)。


## v0.2.1 模型返回处理

结构化资料提取在 DeepSeek 官方接口上关闭思考模式，避免思考占用输出额度导致 JSON 截断；其他兼容接口不额外发送此厂商参数。检测到长度截断会扩容重试，空结果和格式异常也会区分处理。证据校验保持启用。服务端日志仅记录错误分类、结束原因与 token 数量，不记录简历、Key 或模型思考正文。


## v0.3.0 Excel 与 AI 填表

简历生成与启程导入统一导出 Excel，读入用户编辑后的 Excel 作为后续填表唯一资料来源。本地服务新增插件内部 `/plan` 接口用于 AI 字段匹配，不增加本体业务接口。页面操作按钮固定在插件底部。

升级需要重新下载并重新加载浏览器扩展，同时重启本地 `pnpm plugin:serve`；`.env` 配置保持不变。固定扩展标识保持不变。

## v0.4.0 经历明细

- 简历解析生成各类经历的名称、单位、职责、起止日期与详细描述，保存在同一张 Excel 的独立行。空白模板也提供明细行，使用 `experience.work.1.name` 等标识；复制行并修改序号可增加下一条。
- 旧 Excel 只有整段经历时，点击「将表格中的整段经历拆成明细」；只处理当前启用的经历文字，不读取旧简历、不改动已编辑的薪资等字段，并导出更新后的表。旧汇总可能已省略的细节需本人补充或重新解析简历。
- 在底部「本次填写的经历」选择一条，然后 AI 匹配当前已展开的实践/实习/项目表单。保存与添加下一条由本人操作，避免重复写入已保存记录。不会把同一条经历铺满多个空白表单。
- AI 接收章节、日期占位提示和字数限制。描述超限时可逐字摘选本条表格描述，核对区显示摘选提示；其他经历内容、虚构业绩和补造日期会被拒绝。只读/自定义日期选择器、至今复选框仍需本人操作。
- 应用市场下载文件名带版本号，升级到 v0.4.0 后需重新加载扩展并重启本地服务。

## v0.5.0 工作经历与操作反馈

经历明细补充 location（该条工作地点）、department（部门）、responsibilities（工作职责）；role 明确为职位/职务。旧表的 description 可用于工作职责；工作地点缺失时请在 Excel 或插件“查看和编辑表格资料”中为对应经历补充，不会借用现居或意向城市。已有多条经历也会提供各自的补充字段。

支持带 ARIA 关联选项、Element 风格及 Ant Design 风格的常见自定义单选下拉：识别时只展开并读取选项，确认填入后点击实际选项并校验显示结果；选项变化、重复或无法确认时跳过。级联、多选、跨域 iframe、未加载或无法可靠关联的下拉仍需手动核对，不承诺覆盖所有招聘网站。

导入、生成和填写结果会在面板底部持续显示；填写后企业页面显示完成提示，预览及底部反馈列出未填原因。企业页面的保存与提交由本人操作。

### 金证 / 北森 Phoenix 地区控件

根据金证招聘页公开加载的 Phoenix 组件结构，支持普通 Phoenix 单选列表和带搜索、单选地区图标、内部确定按钮的地区选择器（仅 /1 单选模式）。识别阶段仅以所选经历的 location 搜索和读取地区选项，并取消选择器；确认填入后重新搜索、选择具体地区，再点击选择器内部“确定”。不会点击外层简历保存/投递。城市带同名地区时保留地区路径用于匹配，缺少明确地点、无搜索入口、多选或无法确认结果时跳过并提示。登录后的真实表单仍需本人核对。

实现依据：金证公开招聘页面 https://szkingdom1.zhiye.com/campus/jobs 及其公开加载的 Phoenix 组件资源。
